Projects

  • Gaze Reconstruction as Cognitive-State Measurement

    Physics-informed neural network in PyTorch that reconstructs expected gaze from eye-tracking data. Deviation from the reconstruction serves as a measure of attention lapse rather than as tracking error.

    • Multi-head architecture embedding oculomotor dynamics as constraints in the training objective.
    • Outperformed a conventional neural baseline; vertical-gaze R-squared 0.85 to 0.91.
    • Published in Expert Systems with Applications (2025).
  • CourseCrafter — AI-Assisted Course Authoring

    Authoring tool that lets educators build Minecraft Education courses without coding or prior familiarity with the platform’s controls.

    • Evaluated with 10 educators across geographies, grade levels and subjects.
    • Mixed-methods evaluation using the System Usability Scale and semi-structured interviews.
    • Design published at WAIE 2024; evaluation published at AICCONF 2025.
  • Blink-Based Hands-Free Input

    Method separating voluntary from involuntary blinks so that blinks can serve as a reliable input channel, validated as robust under induced stress.

    • Two-component Gaussian mixture model over blink duration establishes the classification boundary.
    • Stress manipulation validated physiologically via pupil diameter; the boundary held.
    • Open dataset and model published on Zenodo.
  • Research Dashboards & Operational Interfaces

    Interface design work turning dense, multi-source data into something people can read and act on, across EU research projects and operational contexts.

    • SCUDO — dashboard unifying multi-source EU project data into a single readable view.
    • Search-and-rescue flight map, designed for legibility under time pressure.
    • Adaptive lecture platform for a relativistic quantum mechanics course.
    • All designed in Figma.
